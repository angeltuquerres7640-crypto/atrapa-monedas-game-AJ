# 🪙 Atrapa las Monedas

Videojuego desarrollado en Python utilizando Kivy.

## Objetivo

Mover la canasta con el dedo para atrapar las monedas que caen.

## Características

- Sistema de puntuación.
- Tres vidas.
- Dificultad progresiva.
- Controles táctiles.
- Pantalla de inicio.
- Pantalla Game Over.
- Botón para reiniciar.
- Compatible con Android.

## Tecnologías

- Python
- Kivy
- Buildozer
- GitHub Actions
